# Chat history

@CHAT_HISTORY.md

`CHAT_HISTORY.md` is the running log of past Claude sessions on this project. Read it to pick up where earlier work left off.

At the end of every task, add an entry to the top of the log (just under the `---`), in this format:

```
## YYYY-MM-DD: <short title>
**Asked:** <what the user wanted, in a sentence or two>
**Done:** <what was changed or answered, naming the files touched>
**Open:** <anything unfinished, untested or needing the user's action; omit if none>
```

Keep entries short: summarise the outcome, don't paste the conversation. Never record secrets (API keys, passwords, tokens) or members' personal details in the log.
